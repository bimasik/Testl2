# 02. Checklist Phase 10

## Перед запуском
- [ ] Созданы структуры статов/визуала для экипировки
- [ ] Создан и заполнен `DT_ItemEquipmentProfile`
- [ ] `BPC_Equipment` имеет `RebuildEquipmentStats` и `RefreshEquipmentVisuals`
- [ ] `BPC_Equipment` кэширует ссылку на компонент статов владельца

## Smoke test в PIE
- [ ] Экипировка корректно повышает нужные статы
- [ ] Снятие экипировки корректно убирает бонусы
- [ ] Visual actor предмета привязывается к нужному сокету
- [ ] При снятии/переэкипировке старый visual actor корректно удаляется
- [ ] При отсутствии профиля в DataTable нет крэша (есть контролируемый warning)
- [ ] UI/состояние инвентаря и экипировки остаются консистентными
- [ ] Нет compile errors

## Definition of Done
Phase 10 закрыта, если:
- итоговые статы персонажа учитывают бонусы всей экипировки;
- визуал экипировки корректно появляется/исчезает на персонаже;
- нет утечек/дубликатов visual actor при переэкипировке;
- система устойчива к неполным данным в DataTable;
- активные способности и сложные боевые модификаторы не добавлялись в этой фазе.
