# Phase 0 (чистая версия)

Этот раздел приведён в порядок и оставляет только нужные инструкции для джуна.
Общий индекс всех фаз: `docs/README.md`.

## Порядок чтения
1. `01_phase0_step_by_step.md` — подробно по итерациям.
2. `02_naming_and_tags.md` — правила именования и Gameplay Tags CSV.
3. `03_data_schema_minimal.md` — минимальная схема данных, без лишних заготовок.
4. `04_phase0_checklist.md` — финальная проверка и критерии завершения.
5. `05_roadmap_compact.md` — компактный пофазный план (одна механика + один основной компонент).
6. `csv/gameplay_tags_master.csv` — готовый CSV для импорта Gameplay Tags.
7. `06_blueprint_rules.md` — обязательные правила по Cast/кэшированию/SRP.

## Главное правило фазы 0
Фаза 0 = **только подготовка проекта**. Без реализации геймплейных механик.
