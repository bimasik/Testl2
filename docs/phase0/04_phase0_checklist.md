# 04. Checklist Phase 0

## Ежедневный быстрый чек
- [ ] Проект открывается
- [ ] Новые ассеты компилируются
- [ ] Нет красных ошибок в Output Log

## Финальный чек (закрытие фазы)
- [ ] Плагины включены
- [ ] Папки `_Core` / `_Modules` созданы
- [ ] Нейминг зафиксирован
- [ ] Gameplay Tags импортируются из CSV
- [ ] Минимальная схема данных задокументирована
- [ ] Baseline commit сделан
- [ ] Геймплейные механики не реализованы

## Definition of Done
Phase 0 закрыта, если все пункты финального чека отмечены.
