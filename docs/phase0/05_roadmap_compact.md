# 05. Компактный roadmap (чистая версия)

Правило: **одна фаза = одна механика + один основной компонент**.

1. **Phase 0**: Bootstrap проекта (без механики).
2. **Phase 1**: Базовое управление персонажем (click-to-move) — `BPC_PlayerControl`.
3. **Phase 2**: Локомоция — `BPC_Locomotion`.
4. **Phase 3**: Таргетинг — `BPC_Targeting`.
5. **Phase 4**: Базовая атака — `BPC_CombatBasic`.
6. **Phase 5**: HP/смерть — `BPC_Health`.
7. **Phase 6**: NPC базовый бой — `BPC_NPCAICombat`.
8. **Phase 7**: Дроп — `BPC_LootDrop`.
9. **Phase 8**: Инвентарь — `BPC_Inventory`.
10. **Phase 9**: Экипировка — `BPC_Equipment`.
11. **Phase 10**: Статы — `BPC_Stats`.
12. **Phase 11**: Активные скиллы — `BPC_Abilities`.
13. **Phase 12**: EXP/SP/Level — `BPC_Progression`.
14. **Phase 13**: Race/Class/Profession — `BPC_Identity`.
15. **Phase 14**: Правила доступа — `BP_RuleEngine`.

Переход на следующую фазу только после DoD текущей.
