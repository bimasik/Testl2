# 03. L2-механики — зафиксированные правила (v1)

Этот файл больше не содержит вопросов. Ниже — согласованные правила, которые используем в реализации.

---

## 1) Управление

### 1.1 Click-to-move и клик по объектам
- ЛКМ по земле -> персонаж бежит в точку клика.
- ЛКМ по NPC/мобу/объекту:
  - первый клик: выделяем (таргетим) объект;
  - повторный клик: подбегаем и выполняем действие (атака/интеракт/действие по контексту).

> В Phase 1 реализуем только «ЛКМ по земле -> бежим».
> Логика таргета/повторного клика уходит в фазы таргетинга и интеракций.

### 1.2 Поворот камеры
- Камера вращается только при зажатой ПКМ.
- Инверсию Y пока не делаем.
- Опция инверсии добавляется позже в настройках игры.

### 1.3 Jump
- Прыжок оставляем как улучшение и допускаем в текущем управлении.

### 1.4 Автоповорот персонажа
- Автоповорот персонажа к цели не делаем.
- Допускается поворот головы к цели (позже, через анимации).

---

## 2) Бой (зафиксировано на будущие фазы)

### 2.1 Выбор цели
- Выбор цели: кликом.

### 2.2 Старт автоатаки
- Автоатака стартует:
  - по клику уже выделенной цели;
  - или при применении скила/действия к выделенной цели.

### 2.3 Движение во время каста
- Во время каста двигаться нельзя.

---

## 3) Визуал и UX (принятые стартовые значения)

### 3.1 Скорость камеры (предложение, принято как дефолт v1)
- Camera Yaw/Pitch Sensitivity: `1.0` (базовое значение).
- Допустимый диапазон для будущих настроек: `0.4 .. 1.8`.

### 3.2 Плавность поворота (предложение, принято как дефолт v1)
- Легкая плавность без «инерционной каши».
- Рекомендованный интерполятор: `RInterpTo` / `FInterpTo` с `InterpSpeed = 10..12`.

### 3.3 Курсор
- Курсор меняется на курсор действия над интерактивными объектами.
